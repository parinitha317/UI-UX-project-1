### Project Scenario
A new fitness startup wants to launch an app for busy office professionals who struggle to find time for exercise.

### Project Objectives
- Define the target audience
- Create user personas
- Identify user goals and frustrations
- Build an empathy map
- Understand the user's needs before designing the product
